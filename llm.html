设计规格 → PM Agent 拆任务 → 编排器排计划 → 可视化执行

① 输入：设计规格 design spec

大模型设置（可跳过，默认走规则）
浏览器直接调接口可能被跨域拦（CORS）。被拦了就切“模拟模型返回”，演示效果一样， 而且不会因为断网翻车。
正在让模型拆任务…
三种拆法：规则解析不联网、最快；调用大模型走 OpenAI 兼容接口（填地址/模型/Key）； 模拟模型返回用于没网或被跨域拦住的时候，效果一样。
上课建议：先规则跑一遍，再切“模拟模型返回”给大家看模型拆出来长什么样。
